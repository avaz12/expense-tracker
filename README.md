# Трекер расходов

Простое веб-приложение для отслеживания доходов и расходов.

## 🌐 Публичный доступ (Онлайн)

Приложение развернуто на платформе Render и доступно в интернете.

https://expense-tracker-t1z4.onrender.com

## 🚀 Развертывание (Deploy)
**Команда запуска** в Render: `uvicorn main:app --host 0.0.0.0 --port 8000`
